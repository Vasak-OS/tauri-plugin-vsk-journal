## Default Permission

Deja que la interfaz escriba en el diario del sistema con el identificador de la
aplicación. No puede elegir ese identificador ni ningún otro campo de confianza:
sólo el nivel y el texto.

#### This default permission set includes the following:

- `allow-registrar`
- `allow-identificador`
